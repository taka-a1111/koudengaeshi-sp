# kg-formstop（2026-10-27 本番反映）

## 内容
Eストアーのアンケートフォーム（/ENQ/enquete.cgi）一時停止中に、問合せ・資料請求・カタログ請求のボタンを押したお客様へ、電話とメールの案内を出す。
クリック時にフォームのアドレスを確かめ、404/410 のときだけ案内を出す。503 や通信失敗は停止とみなさずフォームへ進める。フォーム再開後は案内が出なくなる。

## 実施
- 2026-10-27 12:5x 頃（JST）head追記（func04/newtheme_htmlcustomize.php の include_head_tag_js）の末尾、kg-tally 2026-10-15 end の直後に head_formstop.txt を追加して保存
- 「編集中のテーマでお店を更新」で公開
- 変更前の全文：管理画面タブの localStorage キー kgbk_20261027_include_head_tag_js（243,568字）
- 保存後の読み直し：〜（&#12316;）を正規化して期待値と一致、既存部分は不変
- 公開前後の配信HTML（トップ・クーポン対象商品・口コミ一覧・エクセル注文・特商法）を比べ、差分は kg-formstop ブロックだけ
- 本番で PC（Chrome 実クリック・1280px）、iPhone 13 相当でボタン押下→案内表示を確認。JSエラーなし、横はみ出しなし。ほかのリンクには作用しない
